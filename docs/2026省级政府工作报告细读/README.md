# 2026 年省级政府工作报告细读索引

更新时间：2026-07-17

## 这份索引解决什么问题

来源台账只回答“31 份报告找齐了吗、来源可靠吗”；本目录进一步回答“每份报告真正支持哪些产业方向、支持力度有多强、能否映射到 ETF”。

细读不采用关键词计数。每份报告必须完整阅读，并固定记录：

1. 产业在报告中的真实优先级，而不是出现次数。
2. 预算、基金、开工、投产、扩产、采购和量化目标等落地证据。
3. 产业目前处于研究、招商、建设、投产还是扩产阶段。
4. 与上年报告及“十五五”目标相比的措辞和任务变化。
5. ETF 映射边界：政策支持的具体环节，不能自动外推为整个行业。
6. Codex 核验状态和达达确认状态。

## 审核状态口径

- `Codex 已核验，达达待确认`：可以进入候选证据池，但不能改变正式方向或 ETF 白名单。
- `双方已确认`：可以参与跨省共振比较，但仍须满足全国覆盖和强落地证据门槛。
- `待补材料`：报告已读，但上年报告、五年规划或项目清单仍缺失；缺材料只降低置信度，不等于当地没有落地。

## 后续顺序

第一批青海、江苏、广东、北京、四川用于校准方法；第二批上海、浙江、安徽、福建、山东、湖北、湖南、陕西用于拆分制造科技产业链；第三批辽宁、吉林、黑龙江、山西、内蒙古用于校准资源能源、先进材料和东北工业链；第四批河北、河南、重庆、广西、贵州用于补足汽车、电池、消费制造和西南数智能源材料证据；第五批天津、江西、海南、云南、西藏、甘肃、宁夏、新疆完成全国收官。下一步不再横向扩展产业百科，而是由达达审核全国初筛，再对接近年度白名单的 3–5 组方向下钻重点城市、园区、产业基金、重大项目和一主一备 ETF。
