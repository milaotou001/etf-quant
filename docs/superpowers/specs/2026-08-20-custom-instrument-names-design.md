# 自定义标的名称与加入反馈设计

## 目标

手机或电脑端搜索六位中国股票 / ETF 代码时，页面应优先展示可识别的中文名称。加入目录后，边栏“已有标的”必须立即出现同一名称与代码，便于确认已加入的对象。

## 范围

1. 为六位中国股票 / ETF 代码增加一次名称解析。ETF 和 A 股分别使用现有行情依赖所提供的公开名称数据；结果短期缓存，避免每次页面重跑都联网查询。
2. 临时搜索标的的标题使用“中文名称（代码）”。例如 `512880` 显示为“证券ETF（512880）”。
3. 点击“加入标的”时，将解析后的中文名称和代码一起写入 `mobile/instrument_directory.json`；自定义项仍是“自定义观察”，不获得核心策略、买入计划或回测资格。
4. 若名称来源暂不可用，加入区提供可编辑名称输入框，并以“代码”作为安全兜底。不会把“自定义观察”作为标的名称保存。
5. 写入成功后，显示“已加入：名称（代码）”的明确反馈，并自动重跑页面；边栏选择项以“观察 · 名称（代码）”显示，目录管理页也显示相同标签。

## 数据流与错误处理

搜索代码 -> 校验市场代码 -> 解析可读名称 -> 临时图表标题 / 加入控件 -> GitHub 共享目录文件 -> 重跑读取 -> 已有标的选择器。

名称解析失败不阻断看图或加入：页面提示名称未自动识别并允许手动输入。GitHub 写入失败不显示成功反馈，保留现有明确错误提示；远端目录不变，因此边栏不会假装已更新。

## 验证

- 名称解析函数对解析成功、失败回退和 ETF / A 股分支有单元测试。
- 自定义目录状态保存并应用“名称（代码）”，不再生成“代码 · 自定义观察”。
- 页面测试覆盖：临时标的标题、加入成功反馈、已有标的选择器包含新增标的。
- 运行目录、手机视图和搜索相关测试，以及应用无异常检查。
