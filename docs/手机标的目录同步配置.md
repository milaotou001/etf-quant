# 手机标的目录同步配置

这项功能只同步“要看哪些标的”，不会同步持仓、交易记录、账户余额或买入计划。

## 需要准备的两个值

1. `DIRECTORY_GITHUB_TOKEN`：GitHub 细粒度令牌，只允许修改本项目的目录文件。
2. `DIRECTORY_ADMIN_PIN`：你自己设置的手机目录管理口令。

## 创建 GitHub 令牌

1. 打开 GitHub，进入右上角头像 → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens**。
2. 选择 **Generate new token**，名称可填 `etf-quant-directory`，设置一个合适的过期日期。
3. 在 **Repository access** 选择 **Only select repositories**，只选 `milaotou001/etf-quant`。
4. 在 **Repository permissions** 中，把 **Contents** 设置为 **Read and write**；其他权限保持不授予。
5. 生成后立刻复制令牌。它只会显示一次，不要发送到聊天、微信或保存进项目文件。

## 配置电脑端

打开电脑项目中的 `.streamlit/secrets.toml`，在已有内容后加入（把引号中的内容换成你的真实值）：

```toml
DIRECTORY_GITHUB_TOKEN = "你的 GitHub 令牌"
DIRECTORY_ADMIN_PIN = "你自设的管理口令"
```

这个文件已被 Git 忽略，不会提交到 GitHub。

## 配置手机云端

1. 登录 Streamlit Community Cloud，打开这个应用的设置。
2. 进入 **Secrets**。
3. 在现有内容后加入同样两行 `DIRECTORY_GITHUB_TOKEN` 和 `DIRECTORY_ADMIN_PIN`。
4. 保存 Secrets，等待应用重启。

## 使用方式

- 电脑端：搜索并打开标的图表，页面底部可“加入标的”或“删除标的”；也可从“管理目录”恢复。
- 手机端：先在侧栏输入一次管理口令；本次会话内可在图表页加入/删除，并在“管理目录”恢复。
- 任何一端操作成功后，另一端刷新即可同步。GitHub 会留下每一次目录变更的提交记录。

如果页面提示令牌未配置、无权或网络不可用，目录会安全保持只读，已有图表仍可正常浏览。
