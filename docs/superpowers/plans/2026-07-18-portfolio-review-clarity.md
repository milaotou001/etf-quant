# 组合复盘可读性改造实施计划

> **For agentic workers:** 本计划在当前会话内逐项执行；不引入新依赖，不改变复盘计算口径。

**目标：** 让组合复盘页面先给出直白结论，再展示风险模拟数字，使非量化用户能理解当前风险、主要来源和预算占用。

**架构：** 保留 `portfolio_review.py` 的计算函数和数据结构，只修改 `app.py` 的展示层文案、指标顺序和表格列名；通过 Streamlit 页面实际导航验证可读性与运行无错误。

**技术栈：** Python、Streamlit、现有 unittest 测试。

## 全局约束

- 历史压力回放仍明确标注为模拟，不表述为实际亏损或未来预测。
- 不改变账户基数、回撤预算、风险簇分类或压力回放算法。
- 只预警，不生成买卖指令。
- 不引入新依赖，不修改个人交易缓存。
