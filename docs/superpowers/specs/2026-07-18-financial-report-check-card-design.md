# 财报检查卡设计

## 目标

在“半年买入计划”页面顶部增加一张轻量财报检查卡，让用户不必记住稀土和港股创新药半年报时间，也不把财报日期误解为买入信号。

## 已选方案

采用页面内固定检查卡，不接公告爬虫，也不创建后台任务。相比自动抓取公告，这一方案没有新依赖和数据源故障；相比只在系统日历提醒，它能把检查日期留在买入计划旁边，复盘时不容易脱离上下文。

## 页面内容

- 放置位置：半年买入计划的四项汇总指标之后、计划格之前。
- 标题：`财报检查`。
- 顶部只突出一个“下一检查点”；日期到达后显示“今天检查”或“已到检查时间”，不会把日期到达写成已经完成。
- 固定检查点：
  - 2026-07-20：查看稀土业绩预告和已公布的经营提示。
  - 2026-08-15：查看稀土与港股创新药第一批半年业绩。
  - 2026-09-01：统一复盘两条产业链，决定是否调整观察评级。
- 固定披露窗口说明：A股稀土半年报最迟8月31日；港股创新药初步中期业绩最迟8月31日，详细中期报告最迟9月30日。
- 明确提示：检查日期不是买入日期，公告出来后仍需综合利润、现金流、订单或产品收入判断。

## 数据与边界

- 日期逻辑由独立纯函数生成，输入指定日期即可测试。
- 第一版不自动联网、不统计“已披露几家公司”，避免显示无法可靠维护的进度。
- 不保存完成状态，不改买入计划金额、状态和对账数据。
- 2026-09-01之后仍保留“本轮统一复盘已到期”的提醒，直到后续人工更新研究结论。

## 验证

- 测试7月20日前、检查日当天、8月15日至9月1日前、9月1日后的文案与下一检查点。
- 运行现有全量单元测试。
- 启动Streamlit并确认“半年买入计划”页面可见财报检查卡且无异常。
