# 资产配置研究九份报告重做 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 使用截至 2026-07-22 的一手证据，从零重做 `docs/资产配置研究` 内九份报告并原位替换 Claude 版本。

**Architecture:** 研究分为“产业 H1 兑现检查”和“组合资产/ETF 研究”两组。每份报告只从官方证据台账推导结论，最后统一执行数字追溯、链接检查、Claude 残留扫描和项目状态更新。

**Tech Stack:** Markdown、巨潮资讯/沪深交易所/港交所公告、国家统计局及部委官网、指数公司事实表、基金公司定期报告、本地 Python 行情缓存（仅作技术位置补充）。

## Global Constraints

- 不把旧 Claude 报告内容当作证据或分析起点。
- 不自动改变战略方向、ETF 主备、半年买入计划、持仓或交易规则。
- 关键数字必须附可直接打开的一手来源；缺少一手证据时明确写“材料缺失”。
- 保留九个原文件名，确保项目引用不失效。
- 不覆盖目标文件以外的未知用户改动。
