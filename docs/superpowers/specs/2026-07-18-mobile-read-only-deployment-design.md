# 手机只读版部署设计

## 目标

让达达可以随时用手机私密查看 ETF 当前状态、RSI 等图表和当前买入计划。第一版追求低改动、低维护和隐私安全，不把本地完整工具搬到云端。

## 已选方案

采用 Streamlit Community Cloud 私有应用，不将现有 Streamlit 程序原样部署到 Vercel。Streamlit Cloud 可以直接运行现有 Python 页面，并通过平台登录限制为达达本人；Vercel 若承载当前界面，需要把常驻 Streamlit 服务重写为前端与 Serverless API，超出第一版需求。

如果部署后确认国内行情源在 Streamlit Cloud 上长期不稳定，再把同一只读版迁移到阿里云常驻服务；第一版不同时维护两套部署。

## 第一版范围

手机端只保留两个页面：

1. **状态与图表**
   - 选择现有标的。
   - 显示数据日期、数据来源和缓存状态。
   - 显示现有状态标签、关键数字和观察说明。
   - 显示价格、均线、布林带、RVOL、MACD 和 RSI 图表。
   - RSI 必须保留当前值、阈值和数据日期，不能只显示模糊状态。

2. **当前计划**
   - 显示当前计划总额、已确认金额、待执行金额和笔数进度。
   - 显示各标的的计划金额、批次、当前状态和执行提示。
   - 只读展示，不提供“已买入”、撤销、修改金额或其他写入按钮。

第一版不显示对账单上传、交易记录编辑、复盘日志、组合复盘、完整战役回测、政策研究页和规则说明页。

## 运行模式与代码边界

- 保留本地完整版现有行为，不为手机部署删除本地功能。
- 增加显式的云端只读模式，由部署环境变量开启。
- 只读模式只注册“状态与图表”和“当前计划”两个入口，并从界面层阻断所有写操作。
- 状态、指标和图表继续复用现有 `data.py`、`indicators.py`、`dashboard.py` 和 `chart.py`，不复制第二套计算逻辑。
- 当前计划继续复用 `purchase_plan.py` 的读取和汇总逻辑，但云端不调用保存、对账或状态迁移函数。
- 本地启动时未开启只读模式，原有完整功能保持不变。

## 当前计划的数据来源

- 云端使用一份只读的计划快照，只包含计划展示需要的字段。
- 计划快照通过 Streamlit Secrets 注入，不提交到 Git 仓库，也不从云端页面修改。
- 本地计划发生变化后，重新生成并同步这份快照；第一版不做自动双向同步。
- 云端缺少计划快照或快照格式错误时，页面明确显示“当前计划暂不可用”，不得静默回退到可能过期的默认计划。

## 行情数据与降级

- 云端继续使用现有东方财富、新浪、腾讯三层行情源和现有指标算法。
- 页面始终显示最后一个数据日期，避免把旧数据误认为实时行情。
- 部署包带一份不含私人信息的最近行情只读快照，作为所有在线数据源都失败时的降级数据。
- 在线刷新成功时优先显示新数据；刷新失败时显示降级提示和快照日期，不伪装为已刷新。
- 第一版使用日 K 数据，“随时查看”指随时查看最近可用交易日的 RSI，不提供盘中分钟级 RSI。

## 隐私与访问控制

- 部署前将 GitHub 仓库设为私有，并将 Streamlit 应用设为仅达达本人可访问。
- 使用 Streamlit 平台的 Google 或邮件登录，不在代码中硬编码密码。
- 修正 `.gitignore`，覆盖所有带日期的电子对账单、`private_data`、`journal`、交易缓存、日志、图片和临时研究文件。
- 部署清单采用白名单思路，只包含运行只读版所需代码、依赖、公开市场行情快照和非敏感资源。
- 云端不接收电子对账单，不读取本地交易缓存，不保存买入确认、日志或账户快照。
- 在任何部署命令前检查待上传文件清单，发现账户文件或私人数据立即停止。

## 手机布局

- 手机首屏优先显示标的选择、数据日期、当前状态和 RSI，图表排在其后。
- 桌面端多列指标在窄屏下改为单列或两列，避免横向滚动。
- 缩小手机端页面边距，图表宽度跟随屏幕，图例和文字不得遮挡 K 线。
- “当前计划”按标的使用纵向卡片，不在手机上展示宽表格。
- 保留足够大的选择器和展开控件点击区域。

## 错误处理

- 行情源失败：显示最后可用数据和失败提示，不中断整个页面。
- 单个标的失败：只影响该标的，用户仍可切换其他标的。
- 计划快照失败：状态与图表仍可使用，计划页单独提示不可用。
- 未登录用户：由平台访问控制拦截，不渲染任何财务计划内容。

## 验证

- 运行现有完整单元测试，确认本地完整版没有回归。
- 新增测试覆盖只读模式页面范围、写按钮缺失、计划快照解析失败和行情降级文案。
- 本地分别验证完整版与只读模式，确认环境变量不会串台。
- 使用手机尺寸检查状态首屏、RSI 可见性、图表缩放和计划卡片。
- 部署后验证登录限制、至少两只标的的 RSI 与本地结果一致、计划金额与本地快照一致。
- 检查部署文件清单和 Git 历史新增内容，确认没有电子对账单、交易缓存或私人数据进入提交。

## 非目标

- 不在第一版实现手机上传对账单。
- 不在第一版实现买入标记、计划编辑或云端持久化。
- 不提供盘中 RSI、推送提醒或自动交易。
- 不为 Vercel 重写前端和 API。
- 不改变任何交易规则、指标阈值、计划金额或本地账户数据。
