# 私有手机查看与 Streamlit Cloud 部署设计

## 目标

让达达可以随时用手机私有查看 ETF 日线 RSI、行情图表和当前半年买入计划。第一版以可靠查看为核心，不在云端处理电子对账单，也不提供买入标记、交易日志或其他会修改私人数据的操作。

## 已选方案

采用 Streamlit Community Cloud 私有应用，而不是 Vercel。现有页面已经是 Streamlit，前者可以直接运行常驻 Streamlit 服务；若改用 Vercel，需要重写为前端页面加 Python HTTP API，超出当前只读查看需求。

部署前把现有 GitHub 仓库设为私有，并把应用的查看权限限制为达达本人。第一版不绑定自定义域名；使用固定的 `streamlit.app` 地址和平台登录即可。

如果正式部署后，Streamlit Cloud 从境外访问国内行情源持续不稳定，再把同一套 Streamlit 应用迁移到阿里云。该迁移是故障兜底，不进入第一版范围。

## 运行模式

应用保留两个互不混淆的运行模式：

- 本地完整模式：维持现有功能，可使用本机私有计划、电子对账单、交易缓存和标记操作。
- 云端只读模式：只展示行情、RSI、图表和计划，不渲染文件上传、买入标记、日志创建或其他写入入口。

云端只读模式由部署配置显式开启，不根据主机名或文件是否存在来猜测。只读模式禁止写入私人计划、交易缓存和日志；公开行情缓存仍可使用 Streamlit 缓存或临时磁盘，因为它不属于用户私人状态。

本地完整模式必须保持现有行为，不能因部署改造而丢失对账和标记能力。

## RSI 与行情数据

- 沿用现有 `data.py`、`indicators.py` 和标的目录，不重新实现第二套 RSI 算法。
- 页面继续显示行情日期、数据来源和缓存状态，防止把旧数据误认为当日数据。
- 云端优先实时刷新现有 AKShare 数据源，并沿用已有备用源与缓存逻辑。
- 冷启动时如果所有行情源都失败且没有可用缓存，页面明确显示“本次未取得行情数据”，不能展示伪造数值或静默使用未知日期的数据。
- 上线验收必须至少覆盖 A500、沪深300、黄金、科创50和当前重点/候补 ETF，确认云端实际能取得数据并算出 RSI。

## 当前计划的只读快照

云端不直接读取或提交本机 `private_data`。部署时从本机当前 `purchase_plan.json` 生成只读 JSON 快照，将其作为 Streamlit Secret 保存，不写入 Git 仓库。

只读计划加载器遵守以下规则：

- 云端从 Secret 加载计划，渲染金额、批次、当前状态和剩余计划。
- Secret 缺失、格式错误或版本不兼容时，页面显示清晰错误，不回退成一份看似真实的默认计划。
- 云端不执行对账合并，不自动改变计划状态，也不把任何修改写回 Secret。
- 本机计划发生变化后，再手动生成并更新一次 Secret；第一版不做自动同步。

## 手机页面

- 保留现有页面信息架构，不重新设计整套产品。
- 手机首屏优先显示标的选择、数据日期、当前 RSI 和状态解释；图表与详细指标位于其后。
- “半年买入计划”在窄屏下采用单列或自然换行，金额和批次不能依赖横向滚动才能看全。
- 云端隐藏对账单上传、交易记录管理、日志创建、手动确认按钮，以及仅对本地完整模式有意义的提示。
- 桌面本地页面不因手机适配而退化。

## 隐私与部署边界

- 将 GitHub 仓库从公开改为私有后再连接 Streamlit Community Cloud。
- 部署前扩大 `.gitignore` 对电子对账单文件名的覆盖，确保带日期后缀的 `.xlsx` 也不会被提交。
- 部署前检查 Git 跟踪列表和部署输入，确保不存在 `private_data/`、`journal/`、`cache/`、交易 CSV、电子对账单、照片、日志或密钥。
- Streamlit Secret 只保存只读计划快照和运行模式配置，不保存券商密码、Token 或身份证件信息。
- 应用设置为私有，只授权达达使用的邮箱或 Google 账号；未登录用户不能看到页面内容。

## 不做范围

- 不部署到 Vercel，不重写为 Next.js、Flask 或 FastAPI。
- 不在手机端上传电子对账单。
- 不在手机端标记已买入、修改金额或创建交易日志。
- 不增加数据库、对象存储或自动双向同步。
- 不接入券商 API，不增加自动交易能力。
- 第一版不绑定域名，也不建立额外 CI/CD 工作流。

## 验收

- 本地完整模式的现有单元测试全部通过，对账、标记和日志功能保持可用。
- 新增测试证明只读模式不会渲染或调用私人数据写入入口，计划 Secret 缺失或无效时会明确失败。
- 在约 390 × 844 的手机视口检查首页和半年买入计划页：RSI、数据日期、计划金额和批次无需横向拖动即可阅读。
- 在云端逐只读取目标 ETF，核对 RSI 与同日、本地同算法结果一致。
- 使用未授权会话访问部署地址时，只出现登录或无权限页面；授权账号可以正常打开。
- 部署输入检查中不得出现电子对账单、交易缓存、私人计划原文件、照片或密钥。

## 回退

如果云端行情访问或冷启动体验无法接受，先停止分享 Streamlit Cloud 应用，不改变本地完整模式。之后可以沿用相同只读模式迁移到阿里云常驻 Streamlit 服务，无需重写指标和页面业务逻辑。
